# Data Professional Survey Analysis — Power BI

## 1. Project Overview

This project analyzes survey data collected from data professionals to explore their job roles, salary ranges, favorite programming languages, and job satisfaction.

The goal is to transform raw survey data into a structured dataset and build an interactive Power BI dashboard to present key insights through data visualization.

## 2. Tools & Technologies

- **Power BI Desktop** — Data transformation and dashboard development
- **Power Query** — Data cleaning, transformation, and normalization
- **Microsoft Excel** — Source data format

## 3. Project Workflow

### Step 1: Data Cleaning and Transformation

Used Power Query in Power BI to prepare the raw Excel dataset for analysis.

- Removed unnecessary columns that were not relevant to the analysis.
- Created an `Average Salary` column to support salary analysis.
- Standardized categorical values by consolidating different variations of "Other" into a consistent category.
- Prepared the dataset for visualization and further analysis.

### Step 2: Load Data and Build Dashboard

After completing the data transformation process, loaded the cleaned dataset into Power BI and developed an interactive dashboard.

The dashboard covers the following areas:

- **Survey Overview:** Total number of survey respondents and average age.
- **Job Titles and Salary:** Comparison of salary metrics across different job roles.
- **Programming Language Preferences:** Analysis of respondents' favorite programming languages.
- **Career Entry Difficulty:** Distribution of respondents' perceptions of entering the data field.
- **Job Satisfaction:** Overview of satisfaction with salary and work-life balance.
